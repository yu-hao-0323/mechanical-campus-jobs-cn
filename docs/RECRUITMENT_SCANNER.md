# 每日招聘扫描

GitHub Actions 会在北京时间每天约 08:30 扫描“重点企业雷达”中的企业招聘入口，并把最近一次结果保存到：

- `reports/latest-recruitment-scan.md`：便于直接查看的摘要
- `reports/latest-recruitment-scan.json`：供后续程序处理的完整结果

扫描只检查中国官网或中国区官方招聘页是否出现“校招、应届生、招聘、岗位”等信号，并记录页面是否可访问及页面变化指纹。外企也以中国区官网为准；高校和第三方页面只可作为原始公告参考，不能替代官方入口。它不能可靠识别动态加载页面，也不能替代人工确认。

因此扫描发现线索后，仍需按以下顺序处理：

1. 打开企业官方招聘入口；
2. 确认是 2027 届、仍可投递的校园招聘；
3. 查看完整岗位职责与要求；
4. 只有满足上述条件，才把岗位加入网站的“当前可投”列表。

可以在仓库的 **Actions** 页面打开 “Daily recruitment scan”，点击 **Run workflow** 随时手动执行一次。
